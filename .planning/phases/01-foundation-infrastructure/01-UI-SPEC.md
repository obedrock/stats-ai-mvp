## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline icon-to-label padding |
| sm | 8px | Compact element spacing, button icon padding |
| md | 16px | Default element spacing, form field gap, card padding |
| lg | 24px | Section padding, sidebar section gap |
| xl | 32px | Layout gaps between major regions |
| 2xl | 48px | Auth card vertical padding |
| 3xl | 64px | Page-level spacing (top of auth page) |

Exceptions: Touch targets for icon-only sidebar toggle buttons must be minimum 44px (WCAG 2.5.5 AA). Apply `min-h-[44px] min-w-[44px]` to the collapse icon button.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 500 (medium) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.15 |

**Notes:**
- Body (14px/400) is used for all form inputs, tab content, sidebar list items, and status card text.
- Label (12px/500) is used for form field labels, sidebar section headings, and status step names.
- Heading (20px/600) is used for the auth card title ("Welcome back", "Create account") and the main workspace header.
- Display (28px/600) is reserved for the app logo/wordmark in the sidebar header — used nowhere else in Phase 1.
- Font stack: `font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

## Color

Dark theme. Source: D-07 (CONTEXT.md) — "dark theme with single accent color — modern data tool aesthetic (slate/gray background, light text)."

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (slate-950) | Main background, workspace area, auth page background |
| Secondary (30%) | `#1e293b` (slate-800) | Sidebar background, cards, auth card surface, input backgrounds |
| Accent (10%) | `#6366f1` (indigo-500) | Listed below — reserved for specific elements only |
| Destructive | `#ef4444` (red-500) | Cancel job button, error states only |
| Border | `#334155` (slate-700) | Card borders, input borders, dividers |
| Text primary | `#f1f5f9` (slate-100) | Body text, headings |
| Text muted | `#94a3b8` (slate-400) | Secondary labels, placeholder text, sidebar nav text (inactive) |

**Accent (`#6366f1`) reserved for:**
1. Active tab indicator on the Login / Register tab bar
2. Primary submit button (Log In, Create Account) — background fill
3. Sidebar active item highlight (left border indicator only, not full background)
4. Job status progress indicator (the step dots/line fill as stages complete)
5. Focus ring on all interactive elements (keyboard accessibility)

Accent is NOT used for: inactive states, hover backgrounds, borders, text links, icons in default state.

## Interaction Contracts

These are the specific state machines and interaction behaviors the executor must implement.

### Auth Page (`/auth`)

- Single route with two tabs: "Log In" and "Create Account"
- Default tab: Log In
- Tab switch clears form validation errors but preserves field values
- Submit button shows loading spinner and becomes disabled during the API call
- On successful login: redirect to `/` (workspace) immediately — no toast, no delay
- On successful register: auto-login and redirect to `/` immediately (D-03)
- Error messages appear inline below the relevant field (not a global banner)
- No "show password" toggle required in Phase 1

### App Shell

- Layout: fixed left sidebar (240px expanded, 64px collapsed) + fluid workspace panel
- Sidebar collapse: icon toggle button at bottom of sidebar. Collapses to icons-only mode (D-06)
- Collapsed sidebar shows: app icon, history icon, account icon — tooltips on hover
- Sidebar sections (Phase 1 — stubs only): Logo/wordmark at top, History list (empty), Account info + logout at bottom
- Workspace: full height, scrollable, padding `lg` (24px) on all sides

### Job Status Card

- Appears in workspace area when a job is submitted (Phase 1: triggered by test endpoint)
- Four named steps shown as a stepped progress row: Queued → Fetching Data → Running Analysis → Generating Interpretation
- Completed steps: filled accent dot. Current step: pulsing accent dot. Pending steps: muted dot
- Elapsed time counter updates every second
- Cancel button appears below the step row, right-aligned
- Clicking Cancel shows inline confirmation (see copywriting above)
- On job complete: card transitions to result state (out of scope Phase 1 — card can show "Done" stub)
- On job error: card shows destructive color, plain-English error message, and a "Try again" link
