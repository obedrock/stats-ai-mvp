    1. Create backend/app/services/file_parser.py:
       - Import `pandas as pd`, `io`, `datetime`
       - Function `parse_uploaded_file(content: bytes, filename: str) -> dict`:
         - Detect format by extension: `.csv` -> `pd.read_csv(io.BytesIO(content))`, `.xlsx`/`.xls` -> `pd.read_excel(io.BytesIO(content), engine="openpyxl")`, `.json` -> `pd.read_json(io.BytesIO(content))`

         - Auto-fix step 1: `original_len = len(df)`, drop fully empty rows: `df = df.dropna(how="all").copy()`, record in changes if any dropped
         - Auto-fix step 2: for each object column, attempt `pd.to_numeric(col, errors="coerce")` -- if >80% of non-null values convert successfully, coerce the column and record count in changes
         - Auto-fix step 3: for each object column remaining, attempt `pd.to_datetime(col, errors="coerce", infer_datetime_format=True)` -- if >80% convert, coerce and record
         - Column detection: build list of `{"name": col_name, "detected_type": type_str, "role": None}` where type_str is "numeric" (int/float), "date" (datetime64), "text" (object with >10 unique), "category" (object with <=10 unique)
         - Auto-assign date_index role: if exactly one column is date type, set role="date_index"
         - Return dict with: `preview` (first 10 rows as records), `columns` (list of column info dicts), `changes` (list of change strings), `total_rows` (len(df)), `dataframe` (the cleaned df -- not serialized, for internal use)

    2. Create backend/app/services/frequency_resolver.py:
       - Import `pandas as pd`
       - Function `detect_frequencies(dataframes: dict[str, pd.DataFrame]) -> dict[str, str]`:
         - For each series_id, df pair: `freq = pd.infer_freq(df.index)`, return `freq or "irregular"`
       - Function `check_frequency_conflict(dataframes: dict[str, pd.DataFrame]) -> dict`:
         - Calls detect_frequencies()
         - Gets unique frequencies (excluding None/irregular)
         - If all same or only 1 series: return `{"has_conflict": False, ...}`
         - Otherwise, build FrequencyConflict-shaped dict:
           - series_frequencies: list of {series_id, frequency, row_count}
           - Determine target (lowest frequency -- use mapping: D>B>W>MS>QS>YS)
           - recommendation: human-readable string e.g. "Aggregate {high_freq_series} to {target} via mean"
           - recommended_method: "mean" (default for aggregation to lower frequency)
           - target_frequency: the lowest freq code
           - has_conflict: True
       - Function `apply_resolution(df: pd.DataFrame, target_freq: str, method: str) -> pd.DataFrame`:
         - If method in ("mean", "last", "sum"): `return df.resample(target_freq).agg(method).copy()` (explicit .copy() per pandas 3.0 Pitfall 1)
         - If method == "ffill": `return df.asfreq(target_freq, method="ffill").copy()`
         - Else: raise ValueError(f"Unknown resolution method: {method}")

  <action>
    Create backend/app/services/data_pipeline.py -- the orchestration layer:

    - Import: `pandas as pd`, `numpy as np`
    - Function `clean_and_merge(dataframes: dict[str, pd.DataFrame], metadata: dict | None = None, mode: str = "quick") -> dict`:
      - Takes dict of {series_id: DataFrame} and optional metadata from Claude parsing
      - Initializes `assumptions: list[str] = []`

      **Step 1 -- Timezone normalization (DATA-06):**
      - For each df: if index is tz-naive, `df.index = df.index.tz_localize("UTC")`; if tz-aware but not UTC, `df.index = df.index.tz_convert("UTC")`
      - Assumptions: "Normalized all date indexes to UTC"

      **Step 2 -- Missing value handling (DATA-05):**
      - For each df: count NaN per column
      - Strategy: if <5% missing, forward-fill (`df.ffill().copy()`); if 5-20% missing, linear interpolate (`df.interpolate(method="linear").copy()`); if >20% missing, drop (`df.dropna().copy()`)
      - Drop any remaining NaN rows
      - Assumptions: record which strategy was applied per series (e.g., "GDPC1: forward-filled 3 missing values")

      **Step 3 -- Unit normalization (DATA-07):**
      - If metadata contains unit hints (from Claude parsing): e.g., `{"GDPC1": {"unit": "billions"}, "CPIAUCSL": {"unit": "index"}}`
      - For series in billions: assumptions += "GDPC1 values in billions (no conversion needed)"
      - For percentage series: assumptions += "DFF expressed as percentage"
      - This step primarily documents -- actual conversion happens only if explicitly needed (e.g., billions to millions would multiply by 1000)

      **Step 4 -- Outlier detection (DATA-08):**
      - For each numeric column: compute Q1, Q3, IQR
      - Flag values outside Q1 - 3*IQR, Q3 + 3*IQR
      - Do NOT remove -- just flag: `outlier_flags: dict[str, int]` (series_id -> count of outliers)
      - Assumptions: "AAPL: 2 outlier values detected (not removed)"

      **Step 5 -- Merge (if multiple series):**
      - `merged = pd.concat(dataframes.values(), axis=1, join="inner").copy()`
      - Assumptions: f"Merged {len(dataframes)} series on date index ({len(merged)} overlapping rows)"

      **Step 6 -- Build preview:**
      - preview_rows: `merged.head(50).reset_index().to_dict(orient="records")`
      - column_stats: for each column, compute min, max, mean, missing_count
      - total_rows: len(merged)

      Return dict with: `merged_df` (the DataFrame), `preview_rows`, `column_stats`, `assumptions`, `total_rows`, `outlier_flags`
