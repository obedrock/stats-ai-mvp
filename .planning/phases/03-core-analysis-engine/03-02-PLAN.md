```python
import anthropic
_client = None

def get_client() -> anthropic.Anthropic:
    global _client
    if _client is None:
        _client = anthropic.Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY", ""))
    return _client

# Tool use pattern:
response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=...,
    temperature=0,
    system="...",
    tools=[DETECT_TOOL],
    tool_choice={"type": "tool", "name": "detect_data_sources"},
    messages=[{"role": "user", "content": prompt}],
)
tool_use = next(b for b in response.content if b.type == "tool_use")
return tool_use.input
```

**2. `render_ols_script(dep_var: str, indep_vars: list[str], transformations: str, data_path: str) -> str`**

Reads the R template file from `backend/app/templates/ols_template.R`, replaces the 4 slots:
- `{{DATA_PATH}}` -> `data_path` (the Docker-internal path, e.g., `/data/data.csv`)
- `{{DEP_VAR}}` -> `dep_var`
- `{{INDEP_VARS}}` -> `" + ".join(indep_vars)` (R formula syntax: `X1 + X2 + X3`)
- `{{TRANSFORMATIONS}}` -> `transformations` (raw R code block, or empty string)

Uses `importlib.resources` or `pathlib.Path(__file__).parent.parent / "templates" / "ols_template.R"` to locate the template file. Returns the filled R script as a string.

Import the shared client from series_mapper: `from app.services.series_mapper import get_client`. Do NOT create a second Anthropic client instance.

**1. `interpret_ols_results(prompt: str, r_result: dict) -> dict`**

Calls Claude Stage 2 to interpret successful R results. Returns dict with keys: `interpretation` (str), `follow_up_suggestions` (list of dicts with title/explanation/prompt_text).

- `model="claude-sonnet-4-5"`
- `max_tokens=1024`
- `temperature=0.3` (slight creativity for natural language per RESEARCH.md)
- System prompt (exact text):
  ```
  You are a statistical analyst explaining OLS regression results to an economist. Be precise, reference specific coefficient values and p-values. Write 2-4 paragraphs of plain-English interpretation.

  For follow-up suggestions, reference diagnostic failures directly:
  - If Breusch-Pagan p < 0.05, suggest using robust standard errors or transforming variables
  - If Durbin-Watson statistic < 1.5 or > 2.5, suggest adding lag terms or checking for omitted variables
  - If any VIF > 10, suggest removing highly correlated predictors
  - If Shapiro-Wilk p < 0.05, suggest log transformation of the dependent variable

  Always suggest 2-3 follow-up analyses. Each suggestion must include a complete, ready-to-submit prompt the user can run.
  ```
- `tools=[INTERPRET_TOOL]` with schema:
