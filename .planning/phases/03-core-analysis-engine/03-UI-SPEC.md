## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline separator |
| sm | 8px | Compact element spacing, chip gap row, table cell padding |
| md | 16px | Default element spacing, card padding, section internal gap |
| lg | 24px | Section padding, card content top padding (pt-6) |
| xl | 32px | Layout gaps between result sections |
| 2xl | 48px | Major section breaks in the scrollable results narrative |
| 3xl | 64px | Page-level spacing (not used within results panel) |

Exceptions:
- Diagnostic card row uses gap-3 (12px) between cards — acceptable mid-point between sm and md for compact card grids
- Table cell row height uses py-2 (8px vertical) — the nearest valid multiple-of-4 value. Note: DataPreviewPanel uses py-1.5 (6px) which is pre-existing technical debt in Phase 2; that value is NOT carried forward into this phase.
- Chip row (follow-up suggestions) uses gap-2 (8px) horizontal between chips

## Layout Contract

Results page layout (scrollable single-column narrative, D-01):

```
WorkspacePage
  └─ PromptInput (existing)
  └─ [JobStatusCard while in-progress]
  └─ ResultsSection (replaces JobStatusCard when stage = complete)
       ├─ InterpretationSection        ← anchor: #interpretation
       ├─ CoefficientTable             ← anchor: #coefficients
       ├─ DiagnosticsRow (4 cards)     ← anchor: #diagnostics
       ├─ ChartGrid (2-col → 1-col)   ← anchor: #charts
       ├─ RCodeBlock (collapsed)       ← anchor: #r-code
       └─ FollowUpRow (2–3 chips)      ← anchor: #follow-up
```

Section header style: 16px semibold, text-foreground (#f1f5f9), with a slate-700 separator line above each section (except the first).

Scroll behavior: native browser scroll. No sticky anchors required for MVP.

Error layout (D-09): ErrorResultCard replaces ResultsSection entirely when R fails. Same position in WorkspacePage.

## Interaction Contract

### Diagnostic Badges

Three variants using className overrides on shadcn Badge:
- PASS: `bg-emerald-500/20 text-emerald-400 border-emerald-500/30`
- WARN: `bg-amber-500/20 text-amber-400 border-amber-500/30`
- FAIL: `bg-red-500/20 text-red-400 border-red-500/30`

Pass/warn/fail thresholds (Claude's discretion per CONTEXT.md, standard statistical conventions):
- Breusch-Pagan: PASS p > 0.05, WARN 0.01–0.05, FAIL p < 0.01
- Durbin-Watson: PASS 1.5–2.5, WARN 1.0–1.5 or 2.5–3.0, FAIL < 1.0 or > 3.0
- VIF: PASS < 5, WARN 5–10, FAIL > 10
- Shapiro-Wilk: PASS p > 0.05, WARN 0.01–0.05, FAIL p < 0.01

### R Code Block

- CollapsibleTrigger text (collapsed): "View R Code"
- CollapsibleTrigger text (expanded): "Hide R Code"
- Copy button: lucide `Copy` icon, 16px, text-muted-foreground, hover text-foreground. Placed inline right of the trigger label, visible at all times (not inside collapsible content). On click: copies to clipboard, icon swaps to `Check` for 2 seconds, then reverts.
- Code block background: slate-900 (#0f0f1a — slightly deeper than card), font-mono 12px, rounded-lg, overflow-x-auto with horizontal scroll for long lines.

### Follow-Up Chips (D-12, D-13, D-14)

- Layout: flex-wrap row with gap-2
- Each chip: Button variant="outline", rounded-full, px-4 py-2
- Chip anatomy: bold title (14px semibold) + em-dash + explanation text (14px regular, text-muted-foreground), all inline
- Hover: border-indigo-500, text-foreground
- On click: pre-fills PromptInput with Claude's suggested prompt text, scrolls to top of page (window.scrollTo(0, 0)), does NOT auto-submit

### Error Card (D-09, D-10, D-11)

- Card border: border-red-500
- Heading: "Analysis could not complete" — 16px semibold, text-red-400
- Body: plain-English Claude explanation, 14px text-foreground
- Collapsible raw R stderr: trigger "Show R output" / "Hide R output", content in mono 12px text-red-300
- CTA button: "Try a modified prompt" — accent bg, full width on mobile / auto width on desktop. On click: pre-fills PromptInput with Claude's suggested fix and scrolls to top.

### Plotly Charts (D-03)

- Container: 2-column CSS grid with gap-4, falls back to 1-column below 768px (Tailwind `grid-cols-1 md:grid-cols-2`)
- Each chart: react-plotly.js Plot, `useResizeHandler={true}` and `style={{ width: "100%", height: "360px" }}`
- Plotly layout override: `paper_bgcolor: "transparent"`, `plot_bgcolor: "transparent"`, `font.color: "#f1f5f9"`, `gridcolor: "#334155"` — ensures charts match dark theme

## Accessibility Notes

- All diagnostic badge colors meet WCAG AA contrast on slate-800 card background
- Coefficient table is a semantic `<table>` with proper `<th scope="col">` headers
- R code copy button requires `aria-label="Copy R code to clipboard"` and `aria-live="polite"` region for the "Copied!" feedback
- Follow-up chips must be `<button>` elements (not `<div>`) for keyboard accessibility
- Plotly charts: add `aria-label` to each chart container describing chart type and variables
