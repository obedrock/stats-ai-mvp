The new task signature: `run_ols_analysis(self, job_id: str, prompt: str)`

**Full task flow (10 steps):**

1. `self.update_state(state="PROGRESS", meta={"stage": "preparing", "job_id": job_id})`

2. **Load Job from DB** — Use a synchronous SQLAlchemy session (Celery workers are sync). Create a sync engine and session:
   ```python
   from sqlalchemy import create_engine
   from sqlalchemy.orm import Session
   engine = create_engine(os.environ.get("DATABASE_URL", "sqlite:///./test.db"))
   ```
   Load the Job by `job_id`. Read `cached_data_keys` (JSON array of Redis cache keys from Phase 2 fetch_data).

3. **Reconstruct DataFrame from Redis cache** — Import redis, connect to `os.environ.get("REDIS_URL", "redis://localhost:6379")`. For each cache key in `cached_data_keys`, get the JSON value, parse with `json.loads()` + `pd.DataFrame()`. Then call `clean_and_merge()` from `app.services.data_pipeline` with the individually-loaded DataFrames to ensure column names match the exact output of Phase 2's pipeline (same normalization, same date alignment). Do NOT use raw `pd.merge()` — `clean_and_merge()` guarantees column naming consistency that the R template and Claude Stage 1 depend on.

4. **Get column names** — `column_names = df.columns.tolist()` — these exact names go to Claude Stage 1.

5. **Call Stage 1 Claude** — `slots = generate_ols_slots(prompt, column_names)`. This is a sync call (Anthropic SDK is sync). Extract `dep_var`, `indep_vars`, `transformations`.

6. **Render R script** — `r_script = render_ols_script(slots["dep_var"], slots["indep_vars"], slots["transformations"], "/data/data.csv")`.

7. **Write CSV + R script to tmpdir, run Docker:**
   ```python
   with tempfile.TemporaryDirectory() as tmpdir:
       csv_path = os.path.join(tmpdir, "data.csv")
       df.to_csv(csv_path, index=True, index_label="date")
       script_path = os.path.join(tmpdir, "analysis.R")
       with open(script_path, "w") as f:
           f.write(r_script)
       self.update_state(state="PROGRESS", meta={"stage": "running_r", "job_id": job_id})
       # Docker subprocess — same pattern as existing run_r_analysis but with TWO volume mounts:
       _current_proc = subprocess.Popen([
           "docker", "run", "--rm",
           "--network", "none",
           "--memory", "512m",
           "--cpus", "1.0",
           "--read-only",
           "--tmpfs", "/tmp:size=64m",
           "--user", "1000",
           "-v", f"{script_path}:/analysis.R:ro",
           "-v", f"{csv_path}:/data/data.csv:ro",
           "stats-ai-r-sandbox", "Rscript", "/analysis.R",
       ], stdout=subprocess.PIPE, stderr=subprocess.PIPE)
       stdout, stderr = _current_proc.communicate(timeout=60)
       returncode = _current_proc.returncode
   ```

8. **On R success (returncode == 0):**
   - Parse stdout: `r_result = json.loads(stdout.decode("utf-8"))`
   - Process plotly_charts: each chart has `{"name": ..., "json": "..."}`. Parse the inner JSON string: `chart["data"] = json.loads(chart["json"])` to extract `data` and `layout` keys. Store as `{"name": ..., "data": [...], "layout": {...}}`.
   - `self.update_state(state="PROGRESS", meta={"stage": "generating_interpretation", "job_id": job_id})`
   - Call Stage 2: `interp = interpret_ols_results(prompt, r_result)`
   - Update Job in DB:
     ```python
     with Session(engine) as session:
         job = session.get(Job, uuid.UUID(job_id))
         job.status = "success"
         job.stage = "done"
         job.r_script = r_script
         job.r_result_json = json.dumps(r_result)
         job.result_stdout = stdout.decode("utf-8", errors="replace")
         job.interpretation = interp["interpretation"]
         job.follow_up_suggestions = json.dumps(interp["follow_up_suggestions"])
         session.commit()
     ```

9. **On R error (returncode != 0):**
   - stderr_text = stderr.decode("utf-8", errors="replace")
   - `self.update_state(state="PROGRESS", meta={"stage": "generating_interpretation", "job_id": job_id})`
   - Call error path: `err = explain_r_error(prompt, stderr_text)`
   - Update Job in DB:
     ```python
     with Session(engine) as session:
         job = session.get(Job, uuid.UUID(job_id))
         job.status = "error"
         job.stage = "done"
         job.r_script = r_script
         job.result_stderr = stderr_text
         job.error_explanation = err["error_explanation"]
         job.suggested_prompt = err["suggested_prompt"]
         session.commit()
     ```

10. Return `{"status": job.status, "job_id": job_id}`

**Error handling:** Wrap the entire task in try/except. On any unexpected exception, update Job status to "error" with the exception message in `error_message` field. Re-raise for Celery retry/logging.

**1. Create `backend/app/routers/analysis.py`** with two endpoints:

**`POST /analysis/run`** — Start OLS analysis
- Request body: `AnalysisRunRequest` (job_id + prompt)
- Auth: `user: User = Depends(get_current_user)`
- DB: `db: AsyncSession = Depends(get_db)`
- Logic:
  1. Load Job by `body.job_id` from DB, verify it belongs to the current user (`job.user_id == user.id`), verify it has `status` compatible with running analysis (e.g., job exists and has `cached_data_keys`)
  2. Update job stage to `"running_analysis"` and status to `"running"`
  3. Call `run_ols_analysis.delay(str(job.id), body.prompt)` — get Celery task ID
  4. Store `celery_task_id` on the Job
  5. Commit and return `{"id": str(job.id), "status": "running"}`
- Response: `JobCreated` schema (reuse from existing `backend/app/schemas/jobs.py`)
- Error handling: 404 if job not found, 403 if job belongs to different user, 400 if job has no cached data

**`GET /analysis/{job_id}`** — Poll for analysis results
- Path param: `job_id: str`
- Auth: `user: User = Depends(get_current_user)`
- DB: `db: AsyncSession = Depends(get_db)`
- Logic:
  1. Load Job by `job_id`, verify ownership
  2. If `job.status == "success"`:
     - Parse `job.r_result_json` with `json.loads()`
     - Parse `job.follow_up_suggestions` with `json.loads()`
     - Map R's `plotly_charts` key to API response `charts` key: for each chart in `r_result["plotly_charts"]`, parse the inner JSON string (`json.loads(chart["json"])`) to extract `data` and `layout`, then build `ChartData(name=chart["name"], data=parsed["data"], layout=parsed["layout"])`. This mapping converts R's `{"name": ..., "json": "..."}` format into the `ChartData` schema's `{"name": ..., "data": [...], "layout": {...}}` format.
     - Build `AnalysisResultResponse` with all fields
     - Return it
  3. If `job.status == "error"` and `job.error_explanation` is not None:
     - Return `AnalysisErrorResponse` with error_explanation, suggested_prompt, r_stderr=job.result_stderr, r_code=job.r_script
  4. If still running:
     - Check Celery task state via `celery_app.AsyncResult(job.celery_task_id)`
     - Return `{"status": "running", "stage": result.info.get("stage", "queued") if result.info else job.stage, "job_id": str(job.id)}`
